# 살아있는 지구 (Living Earth)

실시간 데이터로 움직이는 3D 지구본. 낮/밤 경계, 지진, ISS, 위성 궤도가 모두 지금 이 순간의 실제 상태입니다.

## 기능

- 실시간 낮/밤 터미네이터와 도시 야경 — 태양 직하점을 계산해 낮/밤 텍스처를 블렌딩하는 커스텀 셰이더
- 최근 24시간 지진 (USGS, 5분 갱신) — 규모에 따라 크기와 색이 달라지고, M5 이상은 펄스 링
- ISS 실시간 위치와 궤적 (5초 갱신) — 폴링 간격 사이는 보간해 끊김 없이 이동
- 밝은 위성 약 150개의 실시간 궤도 (CelesTrak TLE + SGP4) — 기본은 꺼짐, 클릭하면 궤도선 표시
- 마커를 클릭하면 상세 정보 카드, fps 기반 자동 저사양 모드, 백그라운드 탭 일시정지

## 실행

```bash
npm install
npm run dev       # 개발 서버
npm test          # 유닛 테스트 (Vitest)
npm run e2e       # 스모크 테스트 (Playwright)
npm run build     # 프로덕션 빌드
npm run preview   # 빌드 결과 로컬 프리뷰
```

## 스택

Vite · TypeScript(strict) · Three.js · satellite.js. UI 프레임워크와 서버 없이 동작하는 정적 사이트입니다.

데이터 출처: [USGS Earthquake Hazards Program](https://earthquake.usgs.gov) · [Where the ISS at?](https://wheretheiss.at) · [CelesTrak](https://celestrak.org). 지구 텍스처는 NASA Visible Earth / Blue Marble 이미지입니다.

## 구조

```
src/
  core/     씬, 카메라, 렌더 루프, 클릭 피킹, 성능 프로파일
  globe/    지구본 메시와 셰이더 (낮/밤, 대기 글로우, 태양 위치)
  layers/   데이터 레이어 — 공통 Layer 인터페이스를 구현하는 독립 모듈
  data/     API 클라이언트, 폴링, 백오프, 캐싱
  ui/       토글 패널, 정보 카드, 시계 (일반 DOM)
```

레이어는 서로를 알지 못하고 `init` / `update` / `setVisible` / `setActive` / `dispose` / `getStatus`만 구현합니다. 새 데이터 레이어를 추가하는 일은 파일 하나를 더하는 것으로 끝납니다.

지구본과 셰이더는 API에 의존하지 않으므로, 모든 데이터 요청이 실패해도 지구본은 그대로 렌더됩니다. 레이어는 각자 독립적으로 실패하고, 실패한 레이어만 패널에 사용 불가로 표시되며 지수 백오프로 재시도합니다.

## 테스트

유닛 테스트는 틀리기 쉬운 계산을 순수 함수로 분리해 검증합니다 — 위경도 변환의 극점·날짜변경선 경계, 태양 직하점, USGS/ISS/TLE 파서, 폴러의 백오프와 경쟁 상태, 저사양 판정 로직.

스모크 테스트는 페이지 로드와 콘솔 에러, 레이어 토글, UTC 시계에 더해 캔버스가 실제로 무언가를 그리고 있는지(비검정 픽셀 비율)와 위성 토글이 실제로 마커를 표시하는지를 확인합니다. 세 API는 라우트 가로채기로 고정 데이터를 반환하도록 스텁 처리해 외부 서비스 상태와 무관하게 결정적으로 통과합니다. 실제 스키마 검증은 유닛 테스트의 파서 쪽이 담당합니다.

## 성능

프로덕션 번들은 진입 청크 기준 약 592 kB(gzip 약 156 kB)이고 대부분 Three.js입니다. satellite.js의 WASM SGP4 워커는 별도 청크로 분리되어 위성 레이어를 켤 때만 로드됩니다.

실제 초기 대기를 지배하는 것은 번들이 아니라 지구 낮/밤 텍스처 두 장(합산 약 2.2 MB)입니다. 로딩 중에는 지구본이 어둡게 표시되다가 준비되면 야경이 점등되듯 밝아지는 연출이 그 대기를 덮습니다.

마커는 InstancedMesh로 묶어 레이어당 드로우콜 하나를 쓰고, 애니메이션은 셰이더 유니폼으로 처리합니다. 위성 궤도 계산은 매 프레임이 아니라 초당 두 번만 수행하고 사이는 보간합니다.

## 배포

정적 빌드 산출물이므로 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

```bash
npx vercel --prod
```

**GitHub Pages 프로젝트 페이지에 배포하는 경우**, 애셋 경로가 루트 절대 경로(`/textures/...`)라 서브패스에서는 404가 납니다. `vite.config.ts`에 `base: '/<repo>/'`를 설정해야 합니다.

배포 주소: <https://living-earth-3d.vercel.app>

도메인을 바꾸면 `index.html`의 `og:url`·`og:image`·`twitter:image`도 함께 고쳐야 합니다. 대부분의 플랫폼이 상대 경로를 해석하지 못해 절대 URL로 두었습니다.
